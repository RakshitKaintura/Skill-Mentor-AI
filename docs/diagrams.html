🔐 Authentication Flow

100% 
sequenceDiagram
    autonumber
    participant U as User - Browser
    participant MW as Next.js Middleware - proxy.ts
    participant FE as Next.js Frontend - App Router
    participant CB as Auth Callback - /auth/callback
    participant SA as Supabase Auth
    participant DB as Supabase DB - PostgreSQL
    participant BE as FastAPI Backend

    Note over U,BE: Registration Flow

    U->>FE: Navigate to /auth/register
    FE->>SA: supabase.auth.signUp with email + password + full_name
    SA->>SA: Create auth.users entry
    SA->>DB: TRIGGER handle_new_user - INSERT profiles
    SA-->>FE: Confirmation email sent
    U->>U: Click email confirmation link
    U->>CB: GET /auth/callback?code=PKCE_CODE
    CB->>SA: exchangeCodeForSession with code
    SA-->>CB: JWT Access Token + Refresh Token via Set-Cookie
    CB-->>U: 302 Redirect to /dashboard

    Note over U,BE: Login Flow

    U->>FE: Navigate to /auth/login
    MW->>SA: getUser to check existing session
    SA-->>MW: No session - allow page render
    FE->>SA: supabase.auth.signInWithPassword
    SA-->>FE: JWT Access Token + Refresh Token via Set-Cookie
    FE-->>U: Redirect to /dashboard

    Note over U,BE: Protected Route Access

    U->>MW: Navigate to /dashboard
    MW->>SA: getUser - validate JWT via Supabase

    alt Valid Session
        SA-->>MW: User object returned
        MW->>FE: NextResponse.next - render page
        FE->>FE: useAuth hook - getUser + onAuthStateChange
        FE->>BE: API call with user_id in request body
        BE->>DB: Supabase service_role client - query with user_id
        DB-->>BE: Data with RLS bypassed via service_role
        BE-->>FE: JSON response
    else Invalid or Expired Session
        SA-->>MW: No user or error
        MW-->>U: 302 Redirect to /auth/login
    end

    Note over U,BE: Token Refresh - Automatic

    FE->>SA: onAuthStateChange TOKEN_REFRESHED
    SA-->>FE: New JWT + Refresh Token via Set-Cookie
    FE->>FE: setUser with session.user - state updated silently

    Note over U,BE: Logout Flow

    U->>FE: Click Sign Out
    FE->>SA: supabase.auth.signOut
    SA-->>FE: Session cookies cleared
    FE->>FE: setUser null + setLoading false
    FE-->>U: Redirect to Landing Page

    Note over U,BE: Admin Access

    U->>FE: Navigate to /admin
    FE->>BE: GET /api/admin with X-Admin-API-Key header
    BE->>BE: Verify admin_api_key matches env
    BE->>BE: Verify email in admin_allowed_emails
    alt Authorized
        BE-->>FE: Admin data from platform_stats view
    else Unauthorized
        BE-->>FE: 403 Forbidden
    end

📖 Lesson + Doubt Solving Flow (with RAG)

100% 
sequenceDiagram
    autonumber
    participant U as User
    participant FE as Frontend
    participant BE as FastAPI
    participant LA as Lesson Agent
    participant DA as Doubt Agent
    participant RAG as RAG Service
    participant G as Gemini 3.1
    participant DB as Supabase

    U->>FE: Click topic on roadmap
    FE->>BE: POST /api/lessons/generate
    Note right of FE: user_id, roadmap_id, topic, skill, level
    BE->>LA: Invoke lesson_agent.generate
    LA->>RAG: search_relevant_chunks for topic, skill, user_id
    RAG->>G: embed_content for topic - 768-dim vector
    G-->>RAG: query_embedding
    RAG->>DB: RPC search_book_chunks with embedding, user_id, skill
    DB-->>RAG: Top-K relevant chunks + source_labels
    RAG-->>LA: Context chunks for grounded generation
    LA->>G: generate_content with prompt + RAG context
    G-->>LA: Structured lesson with 6 steps from intro to summary
    LA->>DB: INSERT INTO lessons with steps JSONB and sources_used
    LA-->>BE: lesson_id, topic, steps_count
    BE-->>FE: 200 OK - GenerateLessonResponse
    FE-->>U: Render interactive lesson with step navigation

    Note over U,DB: Student asks a doubt during lesson

    U->>FE: Type question in doubt panel
    FE->>BE: POST /api/lessons/doubt
    Note right of FE: user_id, lesson_id, topic, skill, question
    BE->>DA: Invoke doubt_agent.solve
    DA->>DA: Load lesson context from DB
    DA->>G: generate_content with doubt prompt + lesson context
    G-->>DA: answer, analogy, code_example
    DA->>DB: INSERT INTO doubts
    DA-->>BE: DoubtResponse
    BE-->>FE: 200 OK
    FE-->>U: Display answer with analogy + code

🎙️ Voice Interview Flow

100% 
sequenceDiagram
    autonumber
    participant U as User
    participant FE as Frontend
    participant VH as useVapiInterview Hook
    participant VAPI as Vapi AI - WebSocket
    participant BE as FastAPI
    participant CA as Career Agent
    participant G as Gemini 3.1
    participant DB as Supabase

    U->>FE: Start Mock Interview with skill, type, company
    FE->>BE: POST /api/career/interview/start
    BE->>CA: career_prep_agent.start_interview
    CA->>G: Generate interview questions
    G-->>CA: Structured questions as JSONB
    CA->>DB: INSERT INTO interview_sessions
    CA-->>BE: session_id and questions
    BE-->>FE: Interview session ready

    FE->>VH: Connect Vapi voice session
    VH->>VAPI: WebSocket connect with API key

    loop Per Question
        VAPI-->>U: AI speaks question via TTS
        U->>VAPI: User speaks answer via STT
        VAPI-->>VH: Transcript of user answer
        VH->>BE: POST /api/career/interview/answer
        Note right of VH: session_id, question_index, answer_text
        BE->>CA: Evaluate answer
        CA->>G: Score answer against criteria
        G-->>CA: Evaluation + feedback
        CA->>DB: UPDATE interview_sessions with answers and evaluations
        CA-->>BE: Next question or final feedback
        BE-->>VH: Evaluation result
    end

    VH->>BE: POST /api/career/interview/complete
    BE->>CA: Generate overall assessment
    CA->>G: Summarize performance
    CA->>DB: UPDATE interview_sessions with overall_score and job_ready
    CA-->>BE: Final report
    BE-->>FE: score, strengths, improvements, job_ready
    FE-->>U: Display interview report card

💻 Code Playground (Socratic Coach) Flow

100% 
sequenceDiagram
    autonumber
    participant U as User
    participant FE as Frontend
    participant PH as usePlayground Hook
    participant BE as FastAPI
    participant CC as Code Coach
    participant J0 as Judge0 CE
    participant G as Gemini 3.1
    participant DB as Supabase

    U->>FE: Open code playground for topic
    FE->>BE: POST /api/playground/challenge
    Note right of FE: user_id, topic, skill, difficulty
    BE->>CC: code_coach_agent.generate_challenge
    CC->>G: Generate coding challenge
    G-->>CC: title, description, starter_code, test_cases, hints
    CC->>DB: INSERT INTO code_challenges
    CC-->>BE: Challenge response
    BE-->>FE: Challenge with starter code
    FE-->>U: Render code editor + instructions

    U->>FE: Write code + click Run
    FE->>PH: submitCode with user_code
    PH->>BE: POST /api/v1/sandbox/run
    Note right of PH: source_code, language, test_cases
    BE->>J0: POST /submissions with base64 encoded code
    J0-->>BE: stdout, stderr, status, time, memory
    BE-->>PH: Execution results
    PH->>FE: Display output or errors

    U->>FE: Click Get Hint
    FE->>BE: POST /api/playground/hint
    Note right of FE: challenge_id, current_code
    BE->>CC: Socratic hint with no direct answer
    CC->>G: Generate guiding hint
    G-->>CC: Hint text
    CC-->>BE: Hint response
    BE-->>FE: Display hint and increment hint_count

    U->>FE: Click Submit Solution
    FE->>BE: POST /api/playground/submit
    BE->>CC: Evaluate final solution
    CC->>G: AI code review
    G-->>CC: Feedback + score
    CC->>DB: RPC complete_challenge to award XP
    DB-->>CC: xp_awarded and passed
    CC-->>BE: Evaluation result
    BE-->>FE: passed, xp_awarded, ai_feedback
    FE-->>U: Challenge result + XP animation
